# 🚭 戒烟助手 · AI 戒烟教练

一个**纯前端、离线优先**的戒烟应用——不只是记录工具，而是一个会主动出手的 **AI 戒烟教练**。

## ✨ 核心特性

### 🤖 AI 戒烟教练（Agent）
- **多轮对话干预**：烟瘾来袭时，教练引导你识别触发点（压力/社交/饭后/喝酒/无聊等 8 类）→ 评估强度 → 给出针对性干预话术（基于 CBT 认知行为疗法 + 动机性访谈）→ 记录结果
- **触发画像学习**：统计你的高频触发点、高危时段、扛过去成功率——越用越懂你
- **阶段计划**：6 个戒断阶段（戒断初期 → 巩固期 → 习惯重塑 → 稳定期 → 长期巩固 → 自由人），每个阶段配今日行动清单
- **复吸风险评分**：0-100 加权算法（烟瘾趋势 × 强度 × 复吸占比 × 断签），三档预警
- **可选 LLM 接入**：填写 OpenAI 兼容 API 后，教练话术升级为大模型生成（失败自动回退内置话术）

### 🚨 Agent 主动能力
- **高危时段预测预警**：从烟瘾记录中自动学习你的高危时段（≥2 次/小时），到点前 15 分钟主动提醒（应用内 + 系统通知）
- **健康打卡 + 恢复曲线**：每日记录深呼吸秒数/晨起咳嗽次数/运动分钟，SVG 曲线可视化肺活恢复轨迹
- **每日恢复知识卡**：基于戒烟天数推送对应的身体恢复医学节点（13 个里程碑）+ 每日微行动

### 🫀 3D 器官演变体验
- **20 张 AI 生成的医学级器官插图**（5 器官 × 4 烟龄阶段），演变基于真实病理（焦油沉积、肺气肿、动脉粥样硬化、肝硬化、肾小球硬化）
- **WebGL Shader 2.5D**：深度视差 + 拖拽旋转 + 滚轮缩放，医学图有体积感
- **烟龄滑块**：0 → 30 年，器官在阶段间平滑渐变，配合医学数据面板与冲击文案

### 📊 记录与激励
- 戒烟计时（天/时/分/秒）+ 省钱/少吸/挽回生命统计
- 身体恢复时间线（20 分钟 → 15 年，13 个医学里程碑）
- 每日打卡 + 日历 + 连续打卡天数
- 戒烟周报（烟瘾次数/打卡/省钱）
- 成就徽章（13 枚）+ 可保存的戒烟成绩单海报
- 每日打卡提醒（Notification API）

## 🛠 技术栈

- **纯原生**：单文件 HTML/CSS/JS，无框架、无构建工具
- **Three.js**（本地化于 `libs/`，已预改写依赖路径，零 CDN 依赖）
- **WebGL Shader**：2.5D 深度视差 + 阶段渐变
- **localStorage**：数据全部保存在本机，不上传任何服务器
- **PWA**：Service Worker 离线缓存 + 可安装

## 🚀 快速开始

```bash
# 方式一：npm（推荐，编辑器里也能一键跑）
npm start              # 启动本地服务器 → http://localhost:8123
npm run serve 3000     # 指定端口

# 方式二：Node.js 直接跑
node serve.js

# 方式三：任意静态服务器
python -m http.server 8000
npx serve .
```

> 3D 体验首次需加载约 30MB 医学图（首次后缓存，秒开）。

## 🧑‍💻 本地开发（编辑器友好）

本项目是**零构建**的原生 Web 应用，任何编辑器打开即用，无编译步骤：

| 编辑器 | 用法 |
|---|---|
| **VS Code / Cursor** | 打开文件夹 → 推荐插件会弹窗（Live Server / Prettier）→ `npm start`，或右键 index.html「Open with Live Server」 |
| **WebStorm / IDEA** | 打开文件夹 → 识别 `package.json` → 点 npm 面板的 `start` |
| **Sublime / Vim / 其他** | 直接编辑 `index.html`，保存后刷新浏览器即可 |

**已配置的工程文件**：

| 文件 | 作用 |
|---|---|
| `package.json` | npm scripts（`start` / `dev` / `serve`），编辑器识别为 Node 项目 |
| `jsconfig.json` | JS 智能提示；排除 `libs/` `organs/` 不索引（避免大文件卡顿） |
| `.editorconfig` | 统一缩进（2 空格）、UTF-8、LF 换行，跨编辑器一致 |
| `.vscode/` | 排除大目录搜索/监听，推荐插件 |

> ⚠️ `libs/` 是第三方库（已预改写依赖路径），**请勿格式化**。
